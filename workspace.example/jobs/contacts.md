# Recruiter contacts

One row per message from a recruiter or company, most recent first. The `job-inbox` skill adds the row when you decide what to do with the message. If it turns into an application, the row in `applications.md` is added by `cv-tailor`.

Class: `concrete` · `generic` · `suspicious` · `no-fit`. Decision: `interested` · `asked-info` · `declined` · `applied` · `ignored` (no reply).
